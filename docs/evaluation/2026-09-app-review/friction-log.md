# Friction log

**This file is yours to write in.** It is the one part of the review an agent
cannot do, because friction is what a chemist feels while using the app for
real work, and nobody else can see it.

Write anything that made you pause, retype, hunt for something, or wish the
app had done it for you. Rough notes are ideal. There is no format to keep to,
no need to reproduce anything, and no need to decide whether something counts.
A line like "took me four clicks to get back to the orbital I was looking at"
is exactly the kind of entry that turns into a real improvement.

If you can, say what you were trying to do, because that is usually the part
that gets lost.

These entries are merged into the findings register at step P5.3 as `comfort`
findings, credited to this log. Anything unclear gets asked about rather than
guessed at.
